# Deck: Разряды союзов
Subject: Русский язык
Type: choice

// Союзы по значению: подчинительные и сочинительные.
// Формат: союз (пример или пояснение) -> разряд.
// Как, чтобы и будто бывают подчинительными разных разрядов, да и или — сочинительными,
// поэтому у них есть пример с нужным значением. Пример есть и у слов, которые чаще
// бывают другими частями речи (раз, точно, пусть, же, тоже).

// --- Подчинительные союзы ---

// Временные: когда происходит действие
когда -> Подчинительный временной
пока -> Подчинительный временной
едва (Едва рассвело, мы вышли в путь.) -> Подчинительный временной
как только -> Подчинительный временной
прежде чем -> Подчинительный временной
после того как -> Подчинительный временной
в то время как -> Подчинительный временной
перед тем как -> Подчинительный временной
до тех пор пока -> Подчинительный временной
по мере того как -> Подчинительный временной

// Условные: при каком условии
если -> Подчинительный условный
если бы -> Подчинительный условный
если... то -> Подчинительный условный
раз (Раз обещал, приходи.) -> Подчинительный условный
коли (устар.) -> Подчинительный условный
кабы (устар.) -> Подчинительный условный

// Причинные: почему, по какой причине
потому что -> Подчинительный причинный
так как -> Подчинительный причинный
ибо -> Подчинительный причинный
поскольку -> Подчинительный причинный
оттого что -> Подчинительный причинный
вследствие того что -> Подчинительный причинный
благодаря тому что -> Подчинительный причинный
в связи с тем что -> Подчинительный причинный
тем более что -> Подчинительный причинный
из-за того что -> Подчинительный причинный

// Уступительные: вопреки чему
хотя -> Подчинительный уступительный
хоть (Хоть я и устал, но работу доделал.) -> Подчинительный уступительный
несмотря на то что -> Подчинительный уступительный
невзирая на то что -> Подчинительный уступительный
даром что (Он бодр, даром что стар.) -> Подчинительный уступительный
пусть (Пусть он молод, но опытен.) -> Подчинительный уступительный
пускай (Пускай дорога трудна, мы дойдем.) -> Подчинительный уступительный

// Целевые: зачем, с какой целью
чтобы (Я говорил громко, чтобы все слышали.) -> Подчинительный целевой
дабы (устар.) -> Подчинительный целевой
для того чтобы -> Подчинительный целевой
с тем чтобы -> Подчинительный целевой
затем чтобы -> Подчинительный целевой

// Следственные (союзы следствия): что из этого вышло
так что (Шел дождь, так что мы остались дома.) -> Подчинительный следственный
в результате чего -> Подчинительный следственный

// Сравнительные: как, подобно чему
как (Она пела, как поют соловьи.) -> Подчинительный сравнительный
словно -> Подчинительный сравнительный
точно (Она бежала, точно за ней гнались.) -> Подчинительный сравнительный
будто (Он замер, будто увидел привидение.) -> Подчинительный сравнительный
как будто -> Подчинительный сравнительный
подобно тому как -> Подчинительный сравнительный
чем (Лучше поздно, чем никогда.) -> Подчинительный сравнительный
нежели -> Подчинительный сравнительный

// Изъяснительные: присоединяют придаточное, которое отвечает на вопрос падежа (о чем? что?)
что -> Подчинительный изъяснительный
чтобы (Мама попросила, чтобы я позвонил.) -> Подчинительный изъяснительный
как (Я слышал, как она пела.) -> Подчинительный изъяснительный
будто (Мне показалось, будто кто-то постучал.) -> Подчинительный изъяснительный

// --- Сочинительные союзы ---

// Соединительные
и -> Сочинительный соединительный
да (Жили-были дед да баба.) -> Сочинительный соединительный
и... и -> Сочинительный соединительный
ни... ни -> Сочинительный соединительный
тоже (Брат учится в школе, сестра тоже учится.) -> Сочинительный соединительный

// Противительные
но -> Сочинительный противительный
а -> Сочинительный противительный
да (Мал золотник, да дорог.) -> Сочинительный противительный
однако -> Сочинительный противительный
зато -> Сочинительный противительный
же (Все ушли, я же остался.) -> Сочинительный противительный

// Разделительные
или (Пойдем в кино или в парк?) -> Сочинительный разделительный
либо -> Сочинительный разделительный
ли... ли -> Сочинительный разделительный
то... то -> Сочинительный разделительный
не то... не то -> Сочинительный разделительный
то ли... то ли -> Сочинительный разделительный

// Сопоставительные
как... так и -> Сочинительный сопоставительный
не только... но и -> Сочинительный сопоставительный
хотя и... но -> Сочинительный сопоставительный
если не... то -> Сочинительный сопоставительный
не столько... сколько -> Сочинительный сопоставительный

// Пояснительные
а именно -> Сочинительный пояснительный
то есть -> Сочинительный пояснительный
или (Гиппопотам, или бегемот, живет в Африке.) -> Сочинительный пояснительный
как-то (Купили фрукты, как-то: яблоки, груши, сливы.) -> Сочинительный пояснительный

// Присоединительные
и то -> Сочинительный присоединительный
а то -> Сочинительный присоединительный
да и -> Сочинительный присоединительный
а также -> Сочинительный присоединительный
