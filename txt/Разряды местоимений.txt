# Deck: Разряды местоимений
Subject: Русский язык
Type: choice

// Источник: Грамота.ру.
// Формат: местоимение (пример или пояснение) -> разряд.
// Кто, что, какой, который, чей, сколько бывают вопросительными и относительными,
// а его, ее, их — личными и притяжательными, поэтому у них есть пример с нужным значением.

// Личные: указывают на участников речи или на лица и предметы, не участвующие в диалоге
я -> Личное
ты -> Личное
он -> Личное
она -> Личное
оно -> Личное
мы -> Личное
вы -> Личное
они -> Личное

// Возвратное: указывает на тождественность лица или предмета подлежащему
себя -> Возвратное

// Притяжательные: обозначают принадлежность предмета лицу или другому предмету
мой -> Притяжательное
твой -> Притяжательное
наш -> Притяжательное
ваш -> Притяжательное
свой -> Притяжательное
его (Это его дом.) -> Притяжательное
ее (Она взяла ее тетрадь.) -> Притяжательное
их (Это их класс.) -> Притяжательное

// Указательные: указывают на предмет, признак или количество
этот -> Указательное
тот -> Указательное
такой -> Указательное
таков -> Указательное
столько -> Указательное
сей (устар.) -> Указательное
оный (устар.) -> Указательное

// Определительные: указывают на обобщенный или уточняющий признак предмета
сам -> Определительное
самый -> Определительное
весь -> Определительное
всякий -> Определительное
каждый -> Определительное
любой -> Определительное
другой -> Определительное
иной -> Определительное
всяк (устар.) -> Определительное
всяческий (устар.) -> Определительное

// Вопросительные: служат для выражения вопроса о лице, предмете, признаке или количестве
кто (Кто пришел?) -> Вопросительное
что (Что случилось?) -> Вопросительное
какой (Какой сегодня день?) -> Вопросительное
который (Который час?) -> Вопросительное
чей (Чей это рюкзак?) -> Вопросительное
сколько (Сколько нас?) -> Вопросительное

// Относительные: связывают части сложноподчиненного предложения (союзные слова)
кто (Я знаю, кто пришел.) -> Относительное
что (Скажи, что ты купил.) -> Относительное
какой (Не помню, какой сегодня день.) -> Относительное
который (Дом, который построили, стоит у реки.) -> Относительное
чей (Не знаю, чей это рюкзак.) -> Относительное
сколько (Посчитай, сколько нас.) -> Относительное

// Отрицательные: указывают на отсутствие лица, предмета, признака или количества
никто -> Отрицательное
ничто -> Отрицательное
некого -> Отрицательное
нечего -> Отрицательное
никакой -> Отрицательное
ничей -> Отрицательное

// Неопределенные: указывают на неопределенное лицо, предмет, признак или количество
некто -> Неопределенное
нечто -> Неопределенное
некоторый -> Неопределенное
некий -> Неопределенное
несколько -> Неопределенное
кто-то -> Неопределенное
что-либо -> Неопределенное
какой-нибудь -> Неопределенное
кое-кто -> Неопределенное
