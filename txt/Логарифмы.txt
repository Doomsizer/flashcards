# Deck: Логарифмы
Subject: Математика
Type: build

// Определение и свойства логарифмов. Везде a > 0, a ≠ 1 (так же для c), b > 0, c > 0.
// Формат: Название (пояснение) -> формула. Основание — нижний индекс: log_a b,
// сложное основание или аргумент — в скобках: log_(a^k) b, log_a (bc).

// Определение и простейшие значения
Основное логарифмическое тождество -> a^(log_a b) = b
Логарифм единицы -> log_a 1 = 0
Логарифм основания -> log_a a = 1
Десятичный логарифм -> lg b = log_10 b

// Свойства
Логарифм произведения -> log_a (bc) = log_a b + log_a c
Логарифм частного -> log_a (b/c) = log_a b - log_a c
Логарифм степени -> log_a b^p = p log_a b
Логарифм по основанию-степени -> log_(a^k) b = (1/k) log_a b
Переход к новому основанию -> log_a b = log_c b/log_c a
Перестановка основания и аргумента -> log_a b = 1/log_b a
Произведение логарифмов (цепочка) -> log_a b · log_b c = log_a c
Перестановка в показателе степени -> a^(log_c b) = b^(log_c a)
