# Deck: Формулы тригонометрии
Subject: Математика
Type: build

// Формулы школьного курса тригонометрии.
// Формат: Название (пояснение) -> формула. Формула сама разбивается на части для сборки:
// пробелы разделяют части, ^2 — степень (после степени перед буквой — пробел).
// Аргумент функции из нескольких частей — в квадратных скобках, тогда он станет одной частью
// и проверка поймет его целиком: sin [2α], cos [((α−β)/2)]. Минус внутри скобок — длинный: −.
// Дробь в аргументе — в скобках целиком, чтобы sin((α+β)/2) не читался как sin(α+β), деленный на 2.

// Основное тождество и следствия из него
Основное тригонометрическое тождество -> sin^2 α + cos^2 α = 1
Связь тангенса и косинуса -> tg^2 α + 1 = 1/cos^2 α
Связь котангенса и синуса -> 1 + ctg^2 α = 1/sin^2 α
Тангенс через синус и косинус -> tg α = sin α/cos α
Котангенс через синус и косинус -> ctg α = cos α/sin α
Произведение тангенса и котангенса -> tg α · ctg α = 1

// Двойной угол
Синус двойного угла -> sin [2α] = 2sin α cos α
Косинус двойного угла -> cos [2α] = cos^2 α - sin^2 α
Косинус двойного угла через косинус -> cos [2α] = 2cos^2 α - 1
Косинус двойного угла через синус -> cos [2α] = 1 - 2sin^2 α
Тангенс двойного угла -> tg [2α] = 2tg α/(1 - tg^2 α)

// Синус, косинус и тангенс суммы и разности
Синус суммы -> sin [(α+β)] = sin α cos β + cos α sin β
Синус разности -> sin [(α−β)] = sin α cos β - cos α sin β
Косинус суммы -> cos [(α+β)] = cos α cos β - sin α sin β
Косинус разности -> cos [(α−β)] = cos α cos β + sin α sin β
Тангенс суммы -> tg [(α+β)] = (tg α + tg β)/(1 - tg α tg β)
Тангенс разности -> tg [(α−β)] = (tg α - tg β)/(1 + tg α tg β)

// Сумма и разность синусов и косинусов
Сумма синусов -> sin α + sin β = 2sin [((α+β)/2)] cos [((α−β)/2)]
Разность синусов -> sin α - sin β = 2sin [((α−β)/2)] cos [((α+β)/2)]
Сумма косинусов -> cos α + cos β = 2cos [((α+β)/2)] cos [((α−β)/2)]
Разность косинусов -> cos α - cos β = [−2] sin [((α+β)/2)] sin [((α−β)/2)]

// Произведение в сумму
Произведение косинусов в сумму -> 2cos α cos β = cos [(α+β)] + cos [(α−β)]
Произведение синусов в сумму -> 2sin α sin β = cos [(α−β)] - cos [(α+β)]
Произведение синуса и косинуса в сумму -> 2sin α cos β = sin [(α+β)] + sin [(α−β)]

// Универсальная подстановка
Синус через тангенс половинного угла (t = tg(α/2)) -> sin α = 2t/(1 + t^2)
Косинус через тангенс половинного угла (t = tg(α/2)) -> cos α = (1 - t^2)/(1 + t^2)
Тангенс через тангенс половинного угла (t = tg(α/2)) -> tg α = 2t/(1 - t^2)

// Понижение степени
Понижение степени синуса -> sin^2 α = (1 - cos [2α])/2
Понижение степени косинуса -> cos^2 α = (1 + cos [2α])/2

// Тройной угол
Синус тройного угла -> sin [3α] = 3sin α - 4sin^3 α
Косинус тройного угла -> cos [3α] = 4cos^3 α - 3cos α
