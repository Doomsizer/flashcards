# ЕГЭ Карточки

Карточки для подготовки к ЕГЭ: словари, формулы, ударения. Работает в браузере, на телефоне и на компьютере.

**Сайт:** https://doomsizer.github.io/flashcards/

## Что умеет

- **Коллекции** — на главном экране две коллекции: «Готовые колоды» и «Мои колоды». Внутри колоды сгруппированы по предметам, есть поиск по названию и предмету — и в коллекции, и сразу по всем колодам на главном экране.
- **Свободный режим** — все карточки колоды вразброс, один проход. Во время прохода — счетчик правильных и неправильных ответов, в конце — статистика, список ошибок (их можно сразу добавить в избранное) и повтор только ошибок.
- **Избранное** — список отмеченных ☆ карточек с поиском и очисткой, оттуда же запускается прогон. Избранное хранится в браузере отдельно для каждой колоды.
- **Обучение** — карточки по разделам (по 10 штук), ошибки повторяются до победного, в конце итоговый тест по всей колоде.
- **Ударения** — вместо «знал / не знал» нужно нажать на ударную гласную. Карточка переворачивается и показывает правильный вариант зеленым или красным.
- **Непроверяемые гласные** — под карточкой варианты буквы для пропуска (например, о и а), ответ проверяется сразу.
- **Сборка формул** — в «Обучении» формула разбита на перемешанные части (S, =, π, r, ²), из них нужно собрать формулу и нажать «Проверить». Порядок нестрогий: множители и слагаемые можно ставить в любом порядке, стороны равенства — менять местами (засчитывается любая равносильная запись). В свободном режиме у формул обычные карточки «название → формула».
- **Выбор ответа** — в «Обучении» под карточкой четыре варианта: верный и три других ответа из этой же колоды (например, разряды местоимений). В свободном режиме — обычные карточки.
- **Таблица** (например, для значений тригонометрических функций) — заполнение пропусков в таблице из предложенных вариантов: сначала пропущено одно значение, потом больше, в конце нужно заполнить всю таблицу.
- **Свои колоды** — в коллекции «Мои колоды» можно добавить свою колоду: вставить текст (или загрузить .txt) в том же формате, что и встроенные. Свои колоды хранятся в браузере (IndexedDB), их можно редактировать, удалять и скачивать в .txt, чтобы перенести на другое устройство.

Сейчас есть колоды:

- Значения тригонометрических функций (градусы и радианы)
- Слова с непроверяемой гласной (список ФИПИ)
- Ударения (орфоэпический список ФИПИ – 2026)
- Разряды местоимений (61 местоимение, 9 разрядов, по таблице Грамоты.ру — с выбором ответа)
- Разряды союзов (82 союза: подчинительные и сочинительные по значению — с выбором ответа)
- Формулы геометрии (53 формулы школьного курса: планиметрия, координаты и векторы, стереометрия — со сборкой из частей)
- Формулы тригонометрии (31 формула: основное тождество и следствия, двойной и тройной угол, синус и косинус суммы, суммы и произведения, понижение степени, универсальная подстановка — со сборкой из частей)

## Формат колоды

Один и тот же формат у встроенных колод (`txt/`) и у своих колод на сайте.

Обычная колода:

```
# Deck: Название колоды
Subject: Предмет

вопрос -> ответ
sin 30° (π/6) -> 1/2
```

Колода ударений — по одному слову на строку, ударная гласная заглавная:

```
# Deck: Ударения
Subject: Русский язык
Type: stress

звонИт
Отзыв (о книге)
отзЫв (посла из страны)
```

Колода пропущенных гласных — `(?)` на месте пропуска, под карточкой предлагаются варианты (о/а, е/и, я/е, ю/у…):

```
# Deck: Непроверяемые гласные
Subject: Русский язык
Type: vowel

аб(?)туриент -> абитуриент
к(?)мпания (друзей) -> компания
```

Колода сборки формул — слева название (в скобках можно пояснить, что означают буквы), справа формула, она сама разбивается на части-кнопки:

```
# Deck: Формулы геометрии
Subject: Математика
Type: build

Площадь круга (r — радиус) -> S = pi*r^2
Скорость (v_0 — начальная скорость, a — ускорение, t — время) -> v = v_0 + a*t
Реакция -> [2H₂] + [O₂] = [2H₂O]
```

- `*` и пробелы только разделяют части (умножение без знака), `^2` / `^(n+1)` — степень, `_0` — индекс;
- латинские буквы подряд — отдельные части (`mgh` → m, g, h), а `sin`, `cos`, `log`, `sqrt` и т. п. — целиком; `pi`, `alpha`… показываются греческими буквами;
- `[кусок]` — принудительно одна часть. Так удобно записывать аргумент функции: `sin [2α]`, `cos [((α+β)/2)]` — он станет одной кнопкой, и нестрогая проверка поймет его целиком (без скобок `sin 2α` она прочла бы как `sin 2 · α`).

Колода с выбором ответа — обычные строки «вопрос -> ответ», варианты берутся из других ответов колоды; двусмысленный вопрос можно уточнить примером в скобках:

```
# Deck: Разряды местоимений
Subject: Русский язык
Type: choice

мы -> Личное
кто (Кто пришел?) -> Вопросительное
кто (Я знаю, кто пришел.) -> Относительное
```

Дополнительно:

- `Mode: table` в заголовке включает режим «Таблица». Вопрос карточки делится по первому пробелу на строку и столбец: `sin 30°` → строка `sin`, столбец `30°`.
- Текст в скобках — пояснение. Он не влияет на ID карточки, поэтому избранное не сбрасывается, если пояснение добавить позже.
- Строки, начинающиеся с `//`, — комментарии.
- Повторы и строки с ошибками пропускаются с предупреждением (в консоли при сборке или в предпросмотре на сайте).

## Как добавить встроенную колоду

Положить `.txt` файл в папку `txt/`. При `npm start` и `npm run build` скрипт `scripts/generate-decks.mjs` собирает из них `src/data/generated/`: по JSON на колоду и список колод `deckIndex.js`. Эти файлы генерируются автоматически и не хранятся в git.

Сам разбор формата — в `src/deckFormat/parseDeck.mjs`, его же использует сайт для своих колод.

## Структура

```
src/
  index.js          точка входа: общие стили и App
  app/              каркас: App (какой экран показать), шапка, подвал, экран загрузки
  styles/           общие стили: переменные темы, основа, кнопки, общие блоки
  components/       мелкие общие компоненты: «Назад», стрелка, поле поиска
  features/
    catalog/        главная, коллекции, списки колод
    modes/          меню режимов, свободный режим, обучение, избранное, итоги прохода
    table/          режим «Таблица»
    card/           карточка: переворот, звезда, кнопки ответа, строки в списках
      kinds/        виды карточек: ударения, гласные, формулы и сборка, выбор ответа
    editor/         свои колоды: редактор, памятка, предпросмотр
  deckFormat/       разбор формата колод (общий с генератором)
  hooks/  storage/  utils/
  data/generated/   колоды из txt/ (генерируются, не в git)
public/             шаблон страницы, иконки сайта, манифест
```

Стили компонента лежат рядом с ним, в файле с тем же именем (`Flashcard.jsx` → `Flashcard.css`), и подключаются импортом в самом компоненте — последним. Общие стили (`src/styles/`) подключает `index.js` раньше всех, поэтому стили компонентов могут их уточнять. Базовый класс и его варианты (`.table-cell` и `.table-cell-ok`) держим в одном файле: стили ленивых экранов грузятся в разное время, и уточнение из другого файла могло бы оказаться раньше базового правила.

## Запуск

```
npm install
npm start          # dev-сервер на http://localhost:3000
npm run build      # сборка в dist/
npm run deploy     # сборка и публикация на GitHub Pages (ветка gh-pages)
```

## Стек

React 18, Webpack 5, Babel. Без бэкенда. Колоды и экраны режимов подгружаются лениво — отдельными файлами, только когда нужны, вместе со своими стилями: сразу грузится только CSS главной и меню. Избранное хранится в `localStorage`, свои колоды — в IndexedDB.
